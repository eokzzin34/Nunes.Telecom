# Imagens dos serviços

Coloque aqui as fotos reais da Nunes Telecom usando exatamente estes nomes. O site já está preparado para mostrar cada foto automaticamente:

- `cftv.jpg`
- `PABX.png`
- `alarme.png`
- `cerca.jpg`
- `motor.png`
- `rede.jpeg`
- `interfone.png`
- `concertina.jpeg`
- `manutencao.jpg`

Pode usar JPG ou PNG, mas nesse caso altere apenas a extensão no `src` correspondente do `index.html` (por exemplo, `.webp` para `.jpg`). Recomenda-se uma imagem horizontal, bem iluminada, com pelo menos 1200 px de largura. O arquivo deve mostrar o serviço ou uma instalação real, sem textos pequenos ou informações pessoais visíveis.

Se o arquivo ainda não existir, o card exibe um fundo de espera indicando exatamente onde colocar a foto. Não é necessário alterar o CSS ou o JavaScript.
